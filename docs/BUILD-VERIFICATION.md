# Проверка публикационного набора

Дата: 19 ноября 2026. Проверка выполнялась в отдельном сборочном каталоге,
без установки набора в действующую систему и без перезапуска тестовых сеансов.

## Подготовка

- Полные source snapshots 6.7.4/1.6.0 включены в репозиторий вместе с исходными
  лицензиями и notices. SHA-256 файлов и цели символических ссылок зафиксированы.
- Официальные KDE-архивы скачаны повторно: SHA-256 совпали с архивами стенда.
- `prepare.py` применяет всю серию без отвергнутых hunks.
- Все C/C++-исходники KRdp, Plasma Login Manager и KPipeWire, полученные из
  этой серии, сверены с исходниками рабочей пользовательской сборки: различий нет.
- Выделена отдельная greeter-сборка KRdp с NLA/redirection-патчем, соответствующая
  схеме лабораторного запуска.

При подготовке обнаружена недостающая ранняя серия encoder lifetime changes.
Она восстановлена как `kpipewire-6.7.4-encoder-lifetime.patch` и применяется перед
frame-pool-патчем. Результат сверки приведён выше; без неё старый набор патчей
сам по себе не воспроизводил всю рабочую сборку.

## Регрессионные проверки

`scripts/check-regressions.sh`:

```text
256x192 old-partial: corners_painted=0
384x256 old-partial: corners_painted=0
128x128 old-partial: corners_painted=0
256x192 full-first-frame: corners_painted=1
384x256 full-first-frame: corners_painted=1
128x128 full-first-frame: corners_painted=1
suppress_output_owner_thread=1 close_owner_thread=1
```

Guacamole regression на реальной libguac 1.6.0: исходная библиотека не помечает
полностью замену буфера во всех трёх размерах (ожидаемый exit 1), adapter помечает
(exit 0). В обоих вариантах обычный кадр сохраняет частичную инвалидацию.

Синтаксис shell/Python и ссылки новой документации проверены. Значений рабочих
паролей в отслеживаемых файлах не найдено; приватные ключи, данные ВМ и raw lab
logs не включены. Строковый OpenSSH format header в upstream Guacamole —
константа парсера из оригинального архива, не приватный ключ стенда.

Новая установка всего публикационного набора с перезапуском менеджера входа
не выполнялась. Предыдущий клиентский часовой тест описан отдельно в
[TESTING.md](TESTING.md). Успешная компиляция не заменяет runtime-проверку новой
установки на другой машине.

## Дополнение: ALT Regular JeOS ARM64

В отдельной свежей ВМ собраны варианты KRdp, PLM и согласованная тройка
KPipeWire 6.7.4 с пакетными Qt6.11.3/KF6.32/Plasma6.7.6/FreeRDP3.33.1.
Сравнение 702 подготовленных source-файлов с чистым `prepare.py` совпало.
Build-tree RPATH отключён, тройка KPipeWire разрешается из staging.
Новый тест координат кнопки воспроизводит ошибку исходного обработчика и
проходит после патча. Ввод, два личных сеанса, два переподключения и
реальная смена разрешения проверены в Windows App. Подробности и
ограничения памяти: [ALT.md](ALT.md). Эта проверка не является повторным
GUI-тестом Fedora или Debian с последними изменениями staging.
