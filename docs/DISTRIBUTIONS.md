# Проверка дистрибутивов

Работа начата 19 ноября 2026 года. Матрица ещё не завершена.
Подтверждённый ранее стенд Debian sid описан в [BUILD.md](BUILD.md) и
[BUILD-VERIFICATION.md](BUILD-VERIFICATION.md).

На первом этапе используем UTM на Apple Silicon и официальные ARM64/aarch64
образы там, где они доступны для обычной виртуальной машины. x86_64 будет
проверяться отдельным этапом на Proxmox VE. Эмуляция x86_64 на Mac сейчас
не используется. Immutable-системы исключены.

## Состояние работ

| Дистрибутив / редакция | Первый этап | Подтверждённый результат |
| --- | --- | --- |
| Fedora 45 Cloud Base Generic + установка Plasma | ARM64, UTM | Образ загружен, SHA-256 совпал, система загрузилась, SSH работает; установка зависимостей идёт. Сборка и RDP ещё не проверены. |
| openSUSE Tumbleweed | ARM64, UTM | Официальный UEFI aarch64 установщик найден; ВМ ещё не проверена. |
| РЕД ОС 8 | ARM64, UTM, если универсальный образ загрузится | Официальный ARMv8 образ найден; совместимость с UTM ещё не проверена. |
| ALT Starter Kit p11 KDE | ARM64, UTM | ARM64 ISO и IMG присутствуют в зеркале; ВМ ещё не проверена. |
| ALT Regular KDE | ARM64, UTM | Поиск и получение актуального официального образа продолжаются. |
| ALT Regular JeOS systemd + установка Plasma | ARM64, UTM | Отдельный сценарий чистой базы; ВМ ещё не проверена. |
| ALT «Рабочая станция К» | x86_64, будущий этап PVE | На официальной странице предложена x86_64; ARM64 результат не заявляется. |
| Arch Linux | будущий этап PVE | Не проверен. Arch Linux ARM — отдельный проект, его результат не будет подменять результат Arch Linux. |
| Kubuntu | будущий этап PVE | Не проверен. Ubuntu ARM64 с добавленным KDE не считается проверкой установочного образа Kubuntu. |
| KDE neon | будущий этап PVE | Не проверен. |

Обнаружение образа, загрузка ОС, сборка и проверка RDP — разные результаты.
Статус «работает» появится только после проверки пользовательского сценария.
Fedora Cloud с установленной Plasma также не является проверкой Live ISO
редакции Fedora KDE Plasma Desktop.

## Что проверяем в каждой ВМ

1. Фиксируем редакцию, архитектуру, URL и контрольную сумму образа, версии
   ядра, Qt, KDE Frameworks, Plasma, KRdp, KPipeWire и FreeRDP.
2. Собираем изменённые компоненты из этого репозитория. Записываем все
   изменения зависимостей и путей, необходимые конкретному дистрибутиву.
3. После перезагрузки, без автологина, подключаемся к Plasma Login Manager.
4. Через один RDP-адрес открываем два независимых сеанса разных пользователей.
5. Проверяем клавиатуру, мышь, сохранение открытого Kate и обновление картинки
   после разрыва транспорта и переподключения.
6. Включаем динамическое разрешение, меняем размер окон и полный экран;
   проверяем реальное разрешение Plasma и обновление изображения.
7. Записываем длительность и число циклов проверки памяти. Разделяем активную
   память кодеков и остаток после отключения, указываем RSS/PSS и swap.
8. Сохраняем обезличенные результаты, затем останавливаем и удаляем созданную
   для этой строки ВМ. Существующие лабораторные ВМ в очистку не входят.

SELinux/AppArmor не отключаются глобально для получения положительного
результата. Если понадобятся изменения правил, они будут описаны отдельно.
Репозитории разных выпусков не смешиваются без явного описания такой среды.

## Уже выявленные особенности

Текущий `scripts/build-kde.sh` и `runtime/install-handover.sh` рассчитаны на
Debian. Первый использует `dpkg-architecture`, второй содержит Debian-пути и
настройку PAM. Их нельзя выдавать за готовый установщик Fedora, openSUSE или
ALT. Инструкции для этих систем будут добавляться по результатам реальной
сборки и запуска.

В Fedora 45 ARM64 штатные репозитории на момент начала проверки предлагают
Qt 6.11.2, Frameworks 6.32.0, Plasma Login Manager/KRdp/KPipeWire 6.8.3 и
FreeRDP 3.33.1. Исходники проекта закреплены на Plasma 6.7.4. Минимальные
версии зависимостей выполнены, однако совместимость сборки и библиотек с
Plasma 6.8.3 ещё предстоит проверить. Одних номеров версий для вывода о
работоспособности недостаточно.

Образ первой Fedora ВМ: `Fedora-Cloud-Base-Generic-45-1.4.aarch64.qcow2`,
SHA-256 `1632acc8bc14d45b6c9596a0acc71b070d3748d1abdcf1a519be5c983bb0286c`.
Контрольная сумма сверена с официальным CHECKSUM; проверка его PGP-подписи
на этом этапе ещё не выполнена. Ресурсы ВМ: 4 CPU, 8 ГиБ RAM, диск 40 ГиБ.
