## Регрессионные программы

В `tests/` включены:

- `progressive-surface-roundtrip.cpp`: реальный encoder/decoder FreeRDP,
  первый частичный кадр даёт незакрашенные углы, полный — закрашенные.
- `video-owner-thread.cpp`: вызывает реальные KRdp callback из worker-потока
  и проверяет поток исполнения `enabledChanged` и `closed`.
- `producer-wakeup.cpp`: проверяет используемую KPipeWire синхронизацию
  работы и остановки, включая уведомление до ожидания и 1000 завершений
  двух потоков; входит в `scripts/check-regressions.sh`.
- `drm-dumb-buffer.py`: отдельная Linux-проверка выделения небольшого
  графического буфера на явно указанном DRM-узле от имени пользователя
  сеанса. Не запускается автоматически при сборке.
- `guacamole-external-buffer.c`: на libguac 1.6.0 проверяет полную инвалидацию
  заменяемого внешнего буфера и сохранение частичной инвалидации при обычном кадре.
- `guacamole-hour-load.sh` и `guacamole-hour-memory.py`: ограниченная тестовая
  нагрузка и read-only сборщик памяти. Workload запускает отдельные Konsole
  в двух заданных сеансах; он не запускается автоматически при сборке.

Пример roundtrip после установки FreeRDP development packages:

```sh
mkdir -p build/tests
c++ -std=c++17 tests/progressive-surface-roundtrip.cpp \
    $(pkg-config --cflags --libs freerdp3) -o build/tests/progressive-roundtrip
build/tests/progressive-roundtrip old  # ожидается exit 1
build/tests/progressive-roundtrip      # ожидается exit 0
```

`video-owner-thread.cpp` требует headers и библиотеку собранного KRdp, Qt6,
KPipeWire и FreeRDP. Это fixture с намеренно недействительным сокетом; он удаляет
отложенную инициализацию, чтобы не открывать соединение. Пример точной команды
для проверенной Debian-среды предоставляется скриптом `scripts/check-regressions.sh`.

Guac-regression нужно запускать на машине с libguac **1.6.0**. Сначала соберите
adapter. Для системы, где linker предоставляет `libguac.so.25`:

```sh
cc -O2 -Wall -Wextra -Werror -Iupstream/guacamole-server-1.6.0/src/libguac \
    $(pkg-config --cflags cairo) tests/guacamole-external-buffer.c \
    -l:libguac.so.25 -o build/tests/guacamole-buffer
build/tests/guacamole-buffer  # исходная библиотека: exit 1
LD_PRELOAD="$PWD/build/libguac-external-buffer-resize.so" \
    build/tests/guacamole-buffer  # исправленный путь: exit 0
```

## Открытые вопросы

Требуют дальнейшей проверки: полностью бесшовный resize, точный состав активного
прироста памяти, длительные сеансы, произвольные пользователи/конкурентные
greeter, другие FreeRDP/Plasma-дистрибутивы, многомониторность и production isolation.
Windows App проверялся на предыдущих этапах; именно этот отдельный час выполнен
через Guacamole. Публикационная сборка проверяется отдельно от принятого выше
клиентского часового прогона; новая установка всего набора заново не засчитывается
как ещё один часовой runtime-тест.
