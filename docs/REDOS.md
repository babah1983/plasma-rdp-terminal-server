# РЕД ОС 8 ARM64: проверка зависимостей, RDP пропущен

ВМ не создавалась; сборка и работа RDP **не проверены**. По решению пользователя
проверка пропущена после проверки наличия PLM в официальных ARM64-репозиториях.
Ниже разделены результаты анализа ISO и актуальных онлайн-метаданных.

Официальный универсальный образ:
`redos-8-20260816.0-Everything-aarch64-DVD1.iso`,
[официальный каталог](https://files.red-soft.ru/redos/8.0/aarch64/iso/generic/).
Vendor MD5 совпал: `744cef78b5b499c1aebea3cc2e27d5ac`. Дополнительно
зафиксирован SHA-256:
`789f3c9c0e9d0c6fb84b55a18b5557e749d6cb9b6639b201d930fa56a80e53b9`.
MD5 здесь — проверка совпадения с vendor-файлом, не PGP-проверка подписи.

Метаданные `repodata/*-primary.xml.gz` внутри этого ISO содержат:

| Компонент | Версия на ISO |
| --- | --- |
| Plasma Desktop / Workspace | 5.27.11 |
| KPipeWire | 5.27.11 |
| Qt5 Base | 5.15.18 |
| Qt6 Base | 6.9.3 |
| KDE Frameworks CoreAddons | KF5 5.115.0 |
| SDDM | 0.21.0 |
| FreeRDP | Есть пакеты разных веток, включая freerdp3 3.28.0 |

Точные имена `krdp`, `plasma-login-manager`, `kf6-kcoreaddons` в этих
метаданных не обнаружены. Это не вывод об их отсутствии во всех
актуальных online-репозиториях РЕД ОС.

Исходники прототипа закреплены на Plasma 6.7.4: PLM требует компоненты
Plasma 6.7, KRdp/PLM — Qt 6.10 и KF6 6.26. Поэтому **базовый набор
пакетов данного ISO не соответствует требованиям текущей сборки**.
Установка одного FreeRDP3 или Qt6 не превращает Plasma5 в Plasma6.
Доступные обновления той же ветки проверены ниже по онлайн-метаданным.
Подключение чужих репозиториев и замена системного KDE не выполнялись.

[Извлечённые версии и точное имя primary metadata](evidence/redos8-arm64/iso-packages.json).
Инструкцию установки прототипа для РЕД ОС пока публиковать как проверенную нельзя.

## Онлайн-репозитории: 20 ноября 2026 года

Прочитаны `repomd.xml` и полные primary metadata официальных репозиториев
[os](https://repo2.red-soft.ru/redos/8.0/aarch64/os/),
[updates](https://repo2.red-soft.ru/redos/8.0/aarch64/updates/) и
[extras/kde6](https://repo2.red-soft.ru/redos/8.0/aarch64/extras/kde6/).
В основном репозитории есть Plasma 5.27.3, в updates — Plasma 5.27.11.
Дополнительный `extras/kde6` действительно содержит Plasma 6:

| Компонент | Найден в extras/kde6 | Требуется текущей сборке |
| --- | --- | --- |
| Plasma Desktop / Workspace | 6.4.2 | Компоненты Plasma ≥ 6.7 |
| KPipeWire | 6.4.2 | Закреплённая сборка исходников 6.7.4 |
| KRdp | 6.4.6 | Закреплённая сборка исходников 6.7.4 |
| Qt6 Base | 6.9.3 | ≥ 6.10 |
| KF6 CoreAddons | 6.15.0 | ≥ 6.26 |
| Plasma Login Manager | Не найден | Нужны daemon, helpers, greeter и конфигурация |

Во всех трёх primary metadata отсутствуют пакеты с именами
`plasma-login-manager`, `plasma6-login-manager`, `plasmalogin`, а также любые
имена, совпадающие с `plasma.*login`. Всего разобрано 66 046, 38 105 и
1 997 записей соответственно; это число записей, не уникальных имён.

Контрольные суммы compressed primary сверены с `repomd.xml`,
`open-checksum` проверена при наличии. HTTPS-проверка сертификата включена.
Эта проверка не является PGP-проверкой подписей метаданных или RPM.
[Метаданные, выбранные версии и итог](evidence/redos8-arm64/online/).

По условию пользователя отсутствие пакетного PLM достаточно для пропуска:
ВМ не создавалась и удалять её не потребовалось. Отсутствие зависимостей
также не позволило бы собрать текущий прототип только из этих пакетов.
Вывод ограничен РЕД ОС 8 **aarch64** и указанными снимками репозиториев;
он не переносится на x86_64 и не означает невозможности отдельного портирования.
