# РЕД ОС 8 ARM64: предварительная проверка

ВМ ещё не загружалась; сборка и работа RDP **не проверены**. Этот результат
относится только к read-only анализу репозитория на установочном ISO.

Официальный универсальный образ:
`redos-8-20260816.0-Everything-aarch64-DVD1.iso`,
[официальный каталог](https://files.red-soft.ru/redos/8.0/aarch64/iso/generic/).
Vendor MD5 совпал: `744cef78b5b499c1aebea3cc2e27d5ac`. Дополнительно
зафиксирован SHA-256:
`789f3c9c0e9d0c6fb84b55a18b5557e749d6cb9b6639b201d930fa56a80e53b9`.
MD5 здесь — проверка совпадения с vendor-файлом, не PGP-проверка подписи.

Метаданные `repodata/*-primary.xml.gz` внутри этого ISO содержат:

| Компонент | Версия на ISO |
| --- | --- |
| Plasma Desktop / Workspace | 5.27.11 |
| KPipeWire | 5.27.11 |
| Qt5 Base | 5.15.18 |
| Qt6 Base | 6.9.3 |
| KDE Frameworks CoreAddons | KF5 5.115.0 |
| SDDM | 0.21.0 |
| FreeRDP | Есть пакеты разных веток, включая freerdp3 3.28.0 |

Точные имена `krdp`, `plasma-login-manager`, `kf6-kcoreaddons` в этих
метаданных не обнаружены. Это не вывод об их отсутствии во всех
актуальных online-репозиториях РЕД ОС.

Исходники прототипа закреплены на Plasma 6.7.4: PLM требует компоненты
Plasma 6.7, KRdp/PLM — Qt 6.10 и KF6 6.26. Поэтому **базовый набор
пакетов данного ISO не соответствует требованиям текущей сборки**.
Установка одного FreeRDP3 или Qt6 не превращает Plasma5 в Plasma6.
Перед дальнейшим выводом нужно загрузить официальную систему в UTM
и проверить доступные обновления той же ветки. Подключение чужих
репозиториев и замена системного KDE в рамках этой предварительной
проверки не выполнялись.

[Извлечённые версии и точное имя primary metadata](evidence/redos8-arm64/iso-packages.json).
Инструкцию установки прототипа для РЕД ОС пока публиковать как проверенную нельзя.
